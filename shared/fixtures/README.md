# 계산 결과 검증

`life-cases.json`은 JavaScript와 Swift가 똑같은 시간 값을 계산하는지 확인하는 공통 정답 데이터입니다. 한국·미국 시간대와 기준 수명을 지난 경우를 포함합니다. 향후 Kotlin 구현도 같은 데이터를 테스트에 사용하세요.

계산 규칙:

1. 생년월일은 기기의 시간대에서 그 날짜의 00:00으로 해석합니다.
2. 기준 시점 = 생년월일 + 기준 수명 × 365.2425 × 86400초.
3. 남은 초 = max(0, ceil(기준 시점 − 현재 시점)).
4. 남은 날 = floor(남은 초 / 86400).
5. 지나온 비율 = clamp((현재 시점 − 생년월일) / 전체 기간, 0, 1).

개인의 사망 시점 예측이 아닙니다. 기본값 83.7년의 통계 출처와 제품 의미는 `docs/PRODUCT.md`에 있습니다. 계산 규칙을 바꾸면 계약 설명과 모든 플랫폼의 구현/fixture를 함께 검토하세요.
