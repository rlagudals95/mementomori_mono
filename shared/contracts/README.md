# 플랫폼 간 데이터 계약

`settings-v1.schema.json`은 웹·macOS·향후 iOS/Android가 가져오기/내보내기에 사용하는 JSON 형식을 설명합니다. `settings-example.json`은 개인정보가 없는 테스트용 예시입니다. 런타임 검증은 현재 JavaScript와 Swift에서 구현하며, 스키마를 직접 읽어 검증하는 라이브러리는 사용하지 않습니다.

- `app`: `mementomori`, `version`: `1`.
- `state.profile`: 생년월일과 기준 수명. 없거나 null이면 예시 화면.
- `state.intention`: 날짜가 붙은 오늘의 문장. 없거나 null이면 기본 문장.
- `state.mode`: 웹 상세 화면의 표시 단위. 위젯은 선택한 디자인의 표시 단위를 사용.
- `widget`: 가로형/정사각형/한 줄형과 다크/라이트.
- 다른 버전은 가져오기를 거부합니다. 호환되지 않는 변경은 버전과 마이그레이션 규칙을 함께 추가하세요.
- 실제 달력 날짜인지, 생년월일이 1900년 이후이고 미래가 아닌지 등은 앱에서 추가 검증합니다.
- 파일 크기는 64KiB 이하. 현재 문장 제한은 JavaScript/Swift 모두 UTF-16 코드 단위 100입니다. 스키마의 `maxLength`만으로 이 제한을 완전히 표현할 수 없어 앱에서 검사합니다.

창의 실제 크기·위치는 각 플랫폼의 로컬 UI 설정이며 이 계약에 포함되지 않습니다. 설정 파일에는 생년월일이 있으므로 테스트용 fixture에 실제 사용자 데이터를 넣지 마세요.
