# 공통 디자인 원칙

상세한 디자인 맥락은 저장소 루트 `.impeccable.md`에서 관리합니다. 이 폴더는 웹·Mac·향후 모바일 개발자가 공유하는 원칙을 담습니다. 코드에서 자동으로 생성되는 디자인 토큰 패키지는 아직 필요하지 않습니다.

- 이름: `mementomori.`
- 폰트: Pretendard Variable, 로컬 번들. SIL Open Font License 포함.
- 모노톤: 다크 배경 #151515, 글자 #f7f7f7 / 라이트 배경 #fafafa, 글자 #171717.
- 위젯 모티프: 줄어드는 숫자, 끝이 있는 선, 현재를 나타내는 점.
- 기본 문구: ‘당신의 시간은 유한합니다.’
- 초 디자인: ‘이 1초는 돌아오지 않습니다.’
- 일 디자인: ‘오늘은 다시 오지 않습니다.’
- 예시 프로필에는 예시라고 표시. 직접 작성한 오늘의 문장을 우선 표시.
- 계산 기준은 설정/숫자 도움말에서 확인. 기준을 넘으면 ‘오늘도, 당신의 시간입니다.’와 ‘오늘도 삶은 계속됩니다.’를 표시.

앱별 UI는 각 플랫폼에 맞게 구현하며 글자 크기와 배치는 공간에 맞춰 조정합니다. 공통 문구를 바꾸면 웹과 Mac 코드도 함께 바꾸세요.
