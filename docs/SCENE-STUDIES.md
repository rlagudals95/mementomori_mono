# 좋아하는 세계로 바라보는 시간

2026-09-27. 사용자는 모래시계는 강하게 선호했지만 시지프스·필름·촛불·편도 열차는 컨셉과 맞지 않는다고 평가했다. 기존 네 장면과 해당 상호작용을 현재 시안 코드에서 제거하고, 관심사에서 새롭게 출발한다. 감정 분류를 먼저 선택하게 하지 않는다.

미리보기: `http://localhost:4173/motion.html`. **기본 모래시계 + 음악·독서·자연·게임**을 비교한다. 모노톤·Pretendard·초 카운트를 유지한다. 네이티브 iOS/Mac 앱에 적용하지 않았고 실제 설정을 읽거나 변경하지 않는다.

## 선택 기준

1. 관심사를 표시하는 이름 없이도 좋아하는 대상이 보이는가?
2. 그 대상 자체에서 남은 양 또는 살아낸 양을 읽을 수 있는가?
3. 같은 수명 비율을 다른 대상으로 번역하는가?
4. 짧은 시선과 작은 화면에서도 알아볼 수 있는가?
5. 한 문장을 길게 읽어야만 유한함을 이해하는 장면은 피한다.

음악·독서·자연·게임은 사용자 검증 전의 후보다. 선호 조사나 시장 규모에 근거한 인기 순위가 아니다. 관심사는 마음에 드는 장면을 발견하는 출발점이며, 사람을 고정된 취미 집단으로 분류하는 기능이 아니다.

모래시계는 기본 선택으로 유지한다. 네 새 장면 중에서는 레코드가 관심사의 인식과 남은 양의 표현을 함께 만족하는 우선 후보다. 책은 삶의 목표·기록과 연결할 후보, 나이테는 살아온 경험의 축적을 보여주는 후보다. 게임은 취향이 더 갈릴 가능성을 확인해야 한다. 모두 디자인 판단이며 리텐션이나 행동 변화가 검증된 것은 아니다.

| 관점 | 검토한 다섯 아이디어 |
| --- | --- |
| 제품 | 음악의 남은 트랙, 독서의 남은 장, 자연의 살아낸 나이테, 게임의 남은 생명, 운동의 남은 코스 |
| 디자인 | 레코드와 바늘, 유한한 카세트 테이프, 책의 페이지와 책갈피, 불규칙한 목재 단면, 시작·현재·끝이 보이는 러닝 트랙 |
| 구현 | 수명 비율로 채우는 픽셀 생명 게이지, 현재 비율에서 산출한 바늘 위치, 살아온 해와 전체 해의 챕터 번호, 해마다 한 줄인 나이테, 줄어드는 연필의 남은 길이 |

사용자가 이미 선택한 모래시계를 포함해 다섯 장면으로 비교한다. 카세트는 음악 안에서 레코드와 중복되고 작은 화면에서 남은 테이프를 읽기 어렵다고 판단해 제외했다. 운동 트랙은 경주·성취 경쟁으로 해석될 가능성이 있어 후순위다. 연필은 단순한 잔량을 표현하기 좋지만 관심사가 독서·글쓰기와 겹쳐 이번에는 책을 골랐다. 우주 궤도·파도·계절의 반복은 무한한 순환처럼 읽힐 가능성이 있어 이번 비교에서 제외했다.

## 시간과 상호작용

- 모든 장면은 같은 가상의 남은 `1,797,549,297초`, 전체 83년을 사용한다. 실제 벽시계 경과 시간으로 숫자를 계산한다. 테마 전환이나 버튼으로 초가 늘거나 멈추지 않는다.
- 양과 위치는 수명 비율의 도식이다. 실제 모래 부피·레코드의 길이·나무의 생장에 대한 물리 또는 과학 모델이 아니다. 현재 설정이 개인의 실제 사망 시점이라는 뜻도 아니다.
- 레코드의 회전·커서·현재 나이테의 점·캐릭터의 발 움직임은 흐름을 느끼는 시각 효과다. 몇 초 만에 수십 년이 소진되거나 책의 한 장·나무의 한 해가 매초 지나가는 장면을 만들지 않는다.
- ‘잠깐 멈춰 보기’는 레코드 그림의 회전만 멈춘다. 음악 재생·오디오·계정 연동 기능은 없다. 책갈피는 임시 화면 상태이며 실제 목표·기록 저장 기능이 아니다. 게임도 실제 플레이·점수·건강 상태 기능이 아니다.
- 선택한 장면만 최대 초당30회 렌더링한다. 화면 밖·숨긴 탭에서는 반복 렌더링을 중단하고 복귀 시 현재 초를 다시 계산한다. 모션 재개 시 레코드가 갑자기 빠르게 회전하지 않게 경과를 제한한다.
- OS `prefers-reduced-motion` 또는 ‘움직임 줄이기’에서는 반복 움직임과 전환을 생략한다. 정적인 그림·초 카운트·버튼의 결과는 유지한다. OS 설정을 페이지 선택으로 무시하지 않는다.
- 다크·라이트와 모바일 구성을 제공한다. 테마 탭은 방향키·Home·End, 버튼은 Enter/Space로 조작한다. 각 테마의 그림은 보조 시각 요소이고 수명 정보는 텍스트로도 제공한다.

이 페이지는 실제 앱 적용 전의 후보 비교다. iPhone 홈 위젯에서 앱과 같은 매초 사용자 정의 애니메이션을 제공한다고 약속하지 않는다. 기본 숫자를 유지하고 장면은 정적인 도식으로 제공하는 방향을 먼저 검토한다.

## macOS native implementation

All five interest scenes are available in the floating Mac app, drawn with SwiftUI Canvas (no WebView). The artwork uses the user's actual lifetime ratio and reference lifespan. The book chapter and tree rings follow that same profile. Every shape displays total remaining seconds, including square windows.

Choose a scene in Settings → 시간을 바라보는 방식, or from the widget's right-click menu. Click the art for the theme's small interaction: frame flip, platter pause, bookmark, magnification, or jump. These actions never alter the countdown. The settings preview uses the current profile.

The existing window resize, drag, dark/light palette and Pretendard font remain. Short wide windows put art beside the counter; taller windows put art above it. At the minimum 190×84 size, readability takes priority and the illustration is omitted.

Scene and motion preferences are local Mac UserDefaults keys `scene.theme` and `scene.motion`; the cross-platform settings-v1 JSON contract remains unchanged. Animations respect macOS Reduce Motion and the explicit motion toggle; hiding the floating panel pauses its animation. Countdown timestamps continue to come from the clock, rather than animation frames. Passive motion is limited to 20 frames per second.

## iOS implementation

The same five native scenes appear in the iPhone dashboard and home-screen widgets. App scenes animate and respond to taps; widget scenes are static and keep the existing live seconds text, including split rows for small widgets. The lock-screen counter layout stays compact. Rendering and interaction code are shared with macOS through the MementoScenes Swift package product, without WebViews. Theme selection persists locally and is mirrored to the App Group, followed by a WidgetKit timeline reload request. Widget refresh timing is controlled by iOS.
