# 플랫폼 범위와 기능 기준

현재 제품 개발 대상은 iOS와 macOS입니다. 데스크톱은 Mac만 지원하며 Windows·Linux는 대상이 아닙니다. Android는 후순위이며 아직 앱이나 빌드 환경을 추가하지 않습니다. 웹은 기존 실행 기능을 유지하고 디자인 미리보기에도 사용합니다.

## 현재 구현

| 기능 | iOS | macOS | 웹 |
| --- | --- | --- | --- |
| 생년월일·기준 나이 설정 | 지원 | 지원 | 지원 |
| 앱 화면 초 카운트다운 | 지원 | 지원 | 지원 |
| 자주 보는 표시 형태 | 홈·잠금화면 OS 위젯 | 항상 위에 표시되는 작은 창 | 위젯 미리보기·지원 브라우저의 작은 창 |
| 가로형 숫자 | 총 초 또는 일 | 총 초 | 총 초 |
| 정사각형 숫자 | 총 초 두 줄 또는 일 | 일 | 일 |
| 표시 방식 선택 | 앱의 초/일, 개별 위젯 설정 | 가로형·정사각형·한 줄형 | 가로형·정사각형·한 줄형 |
| 크기 변경 | OS가 제공하는 작은·중간 위젯 | 창 가장자리 드래그 | 미리보기 모서리·브라우저 창 |
| 다크·라이트 | 위젯 설정 | 지원 | 지원 |
| 오늘의 문장 | 앱, 중간 홈 위젯 | 지원 | 지원 |
| JSON 설정 가져오기·내보내기 | 지원 | 지원 | 지원 |
| 자동 기기 간 동기화 | 없음 | 없음 | 없음 |

iOS 홈 위젯은 두 크기 모두 초/일 선택을 따릅니다. 작은 위젯에서 총 초는 두 줄로 표시합니다. 잠금화면 직사각형은 초/일, 인라인은 남은 일, 원형은 지나온 비율을 표시합니다. 시스템에 의한 초 갱신은 iOS 18 이상에서 사용하며 OS 표시 정책의 영향을 받습니다. iOS 17은 timeline 시점의 숫자를 표시합니다.

Mac·웹의 정사각형은 기존 일 단위 디자인을 유지합니다. 이번 관리 작업에서는 표시 동작을 바꾸지 않습니다. 기능을 통일하거나 차이를 추가할 때 이 표와 해당 플랫폼 문서도 함께 변경합니다.

## 공통으로 유지할 규칙

- 생년월일 해석, 기준 시점, 반올림, 0 아래로 내려가지 않는 계산은 `shared/fixtures/life-cases.json`으로 검증합니다.
- 설정 교환은 `shared/contracts/settings-v1.schema.json`을 따릅니다. 호환되지 않는 변경에는 버전과 마이그레이션이 필요합니다.
- 기본 브랜드·문구·폰트·색상은 `shared/design/README.md`를 따릅니다. UI 배치와 갱신 방식은 플랫폼 안에서 구현합니다.
- 저장소는 하나지만 빌드·서명·출시는 플랫폼별로 수행합니다. 현재 저장소의 통합 검증은 `npm run test:all`입니다.
- 공용 Swift package는 iOS·Mac 계산을 공유합니다. Android 개발을 재개할 때는 Kotlin 구현도 동일한 fixture로 검사합니다.

상용 배포용 서명, 자동 업데이트, 스토어 제출, 동기화 서버는 현재 구현 범위에 포함하지 않습니다.
