# 검증 기록

검증일: 2026-09-26. macOS, Node.js 22.22.0, Google Chrome 153, Playwright 1.63.

## 통과

- `npm test`: 계산·복원 단위 테스트 8개 통과.
  - 실제 달력 날짜와 윤일 검증.
  - 미래 생일, 비정상 수명 입력 거부.
  - 긴 백그라운드 중단 뒤에도 시각 차이에 맞는 남은 시간.
  - 일·시·분·초 분해.
  - 기준 수명을 지나도 남은 시간은 0, 비율은 100%를 넘지 않음.
  - 손상되거나 접근할 수 없는 저장소 처리.
  - 저장 데이터 필드 검증, 문장 길이 제한.
  - 기기 현지 날짜 생성.
- `npm run build`: 배포용 정적 파일 생성 성공. 최초 버전은 폰트 포함 약 1.1MB; Pretendard Variable 적용본은 약 2.1MB.
- `npm run test:browser`: Chrome 브라우저 흐름 테스트 5개 통과.
  - 생일 설정, 초 단위 감소, 문장과 보기 모드 저장, 새로고침 복원, 기록 삭제.
  - 빈 입력·미래 날짜 오류와 기준 수명을 지난 화면.
  - 390px 모바일 너비, 가로 넘침 없음, 집중 화면 진입·종료, HTML 형태의 입력을 텍스트로 취급.
  - 첫 온라인 캐시 준비 후 네트워크를 끊고 새로고침해도 저장된 설정과 타이머 복원.
  - Document Picture-in-Picture 창 생성, 카운트다운 감소, 창 닫기.
- 1440px 데스크톱, 390px 모바일의 전체 화면을 캡처해 시각적으로 확인.
- 서비스 화면에서 외부 API·웹폰트 요청 없이 동작하도록 폰트 번들 포함.

브라우저 테스트 중 오프라인 정적 파일 조회가 preview 서버의 `Vary: Origin` 헤더에 영향을 받는 문제를 발견했다. 동일 출처의 고정 배포 파일에 한해 캐시 매칭 시 Vary를 무시하도록 수정한 뒤 전체 브라우저 테스트를 다시 통과했다.

## 드래그 크기 조절 — 2026-09-26

- Mac 패널에 시스템 가장자리 크기 조절과 오른쪽 아래 전용 손잡이를 추가. 최소 190×84, 최대 1200×1000이며 사용 가능한 화면 안으로 보정한다.
- 실제 크기로 SwiftUI 화면을 배치하며 세로형에서는 숫자와 아래 문장 사이에 여백을 둔다. 크기를 바꿔도 선택한 표시 단위는 유지한다.
- 창 너비·높이를 저장하고 재실행 시 복원. 프로필·테마 변경은 수동 크기를 초기화하지 않음. 메뉴바에 기본 크기 복원 추가.
- 웹 미리보기의 CSS resize와 실제 PiP 창의 ResizeObserver를 통해 같은 레이아웃 규칙 적용. 테마 변경 시 미리보기 크기 유지.
- 브라우저 테스트 9개 통과. 추가 테스트는 실제 마우스 드래그로 세로형 전환, 숫자 가독성, 테마 전환 후 크기 유지를 확인.
- Mac release 빌드/로컬 서명 통과. 실행된 창이 서로 다른 너비·높이에 반응하는 화면 확인. 마지막 높이 제한 보정은 빌드 확인했으며, 사용자 작업 중인 앱은 강제 종료하지 않음. 최종 빌드를 적용하려면 앱을 종료 후 다시 실행한다.

## 위젯 문구 개선 — 2026-09-26

- 모호한 ‘기준까지 남은 시간’을 실제 설정 나이를 넣은 ‘83.7세까지 남은 시간’으로 변경. 설정을 바꾸면 해당 나이를 표시한다.
- 초 위젯 기본 문장: ‘이 1초는 돌아오지 않습니다.’ / 일 위젯: ‘오늘은 다시 오지 않습니다.’
- 퍼센트 앞에 ‘지나온’을 표시. 기준을 넘으면 ‘83.7세를 넘어, 오늘도’와 ‘오늘도 삶은 계속됩니다.’를 표시한다.
- 사용자가 직접 입력한 오늘의 문장은 유지한다. 예시 프로필에는 예시 표기를 유지한다.
- 웹/Mac 빌드 통과, 기존 웹 단위 테스트 12개 및 브라우저 테스트 9개 통과. 웹 세로형 화면에서 새 문구 표시 확인. 실행 중인 Mac 앱은 사용자 입력 보존을 위해 강제 재시작하지 않았다.


## 모노레포 이전 — 2026-09-26

- 웹 소스/정적 파일/구성/테스트를 `apps/web`, Swift package/테스트를 `apps/macos`로 이동.
- 루트 npm workspaces와 단일 package-lock.json 적용. 기존 루트 실행 명령 유지.
- 공통 설정 예시와 스키마를 `shared/contracts`, 계산 정답 데이터를 `shared/fixtures`, 디자인 원칙을 `shared/design`에 정리.
- JavaScript 및 Swift fixture 경로, Playwright 결과 경로, Mac 패키징/아이콘 생성 경로 수정.
- `npm ci`, 웹 빌드, Mac release 빌드와 로컬 서명, 아이콘 생성 성공.
- 웹 단위 테스트 12개, 브라우저 테스트 9개, Swift 테스트 5개 통과 (총 26개).
- 웹 preview를 새 workspace에서 port 4173으로 실행. 기존 앱 bundle identifier와 로컬 저장 키를 유지하여 사용자 설정 위치는 변경하지 않음.
- 빌드 캐시는 새 경로에서 다시 생성했으며 기존 Swift 캐시는 ignored artifacts 아래 보관. 빌드 파일/캐시의 Git 제외 확인.
- GitHub checks workflow 추가. 원격 GitHub 실행/외부 배포는 하지 않음.
- 과거 검증 기록의 소스 경로는 이전 당시 기록이며 최신 경로는 루트 README와 ARCHITECTURE.md를 따른다.

- 시스템 UI의 검색 결과는 button이 아닌 cell이고 ‘위젯 추가’ 라벨에 앞 공백이 있어 초기 자동화 탐색이 실패했다. 시스템 검색 입력을 완료하고 cell/라벨을 맞추어 최종 위젯 추가 테스트를 통과했다.

- iPhone 16e 시뮬레이터에서 `dev:ios`로 앱 실행 및 시작 화면 확인. 테스트 프로필(2000-01-01)로 앱 숫자/달력/폰트 화면을 확인했다. 실제 사용자 생년월일을 사용하지 않았다.
- 결과 화면: 로컬 ignored 경로 `artifacts/ios/iphone-countdown.png`, `artifacts/ios/home-widget.png`. 앱·확장에 Pretendard 라이선스와 개인정보 manifest를 포함했다.

### 남은 기기 검증

- 연결된 iPhone이 없어 Personal Team 서명·USB 실기기 설치·7일 후 재설치는 하지 않았다. 사용자가 Xcode 계정과 두 target의 Team을 선택해야 한다.
- 홈 위젯의 설정 전 표시와 추가 경로는 시뮬레이터에서 확인했다. 위젯 편집에서 실제 개인 프로필 입력, 시스템 타이머, 잠금화면 각 가족, Always-On/저전력 모드, iOS 17~25는 실기기에서 추가 확인해야 한다.
- 앱과 위젯은 데이터를 각각 저장한다. 자동 공유와 클라우드 동기화는 포함하지 않는다. 위젯의 AppIntent 설정과 앱의 UserDefaults는 구분하여 설명했다.
- 앱은 초 단위 총 초 숫자, 위젯은 일 또는 시스템의 시간:분:초 표시이다. WidgetKit 갱신과 timeline 전환은 OS 정책에 따라 지연될 수 있다.
- JSON 계산/계약 검증은 공용 테스트로 확인했다. iOS 파일 선택기와 Files 앱을 통한 가져오기/내보내기 전체 UI 왕복은 추가 수동 검증이 필요하다.
- CI에 iOS 빌드/테스트 job을 추가했다. 이번 기록은 로컬 결과이며 원격 CI 결과와 별개이다.
