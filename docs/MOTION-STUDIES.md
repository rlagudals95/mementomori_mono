# 카운트다운 움직임 시안

2026-09-27. 앱·Mac에 적용할 수 있는 움직임을 웹에서 비교하는 시안입니다. 실제 앱에 적용하지 않았습니다.

주소: `http://localhost:4173/motion-minimal.html`. 최초의 세 시안을 보관한 화면입니다. 이후 사용자가 숫자 효과를 벗어나는 시안을 요청하여 `/motion.html`을 [시간의 다섯 장면](SCENE-STUDIES.md)으로 교체했습니다. 기존 웹 preview 서버에서 실행하며 `npm run build` 결과에 포함됩니다. 가상의 동일한 시간이 세 시안에서 실제 경과 시간에 맞춰 줄어듭니다. 실제 생년월일·저장된 설정은 읽거나 변경하지 않습니다.

| 시안 | 움직임 | 상호작용 | 의미 |
| --- | --- | --- | --- |
| 사라지는 한 초 | 바뀐 숫자의 이전 값이 380ms 동안 아래로 9px 사라짐 | 탭하면 직전 한 초의 흔적을 조금 더 선명하게 보여줌 | 지나간 시간은 돌아오지 않음 |
| 지금의 파문 | 선 위 현재 점의 아주 작은 원이 650ms 동안 희미하게 번짐 | 탭하면 480ms의 조금 큰 파문 | 지금이 순간마다 지나감 |
| 잠깐 붙잡은 순간 | 누른 시점의 숫자를 작은 문장으로 남김, 큰 숫자는 계속 감소 | 누르는 동안 기록 유지, 놓으면 잠시 뒤 사라짐; Space/Enter도 지원 | 순간을 바라볼 수 있어도 시간을 멈출 수는 없음 |

모노톤·Pretendard·숫자·끝이 있는 선을 유지합니다. 매초 움직이는 것은 해당 시안의 한 요소뿐입니다. 숨긴 탭은 타이머를 중단하고 복귀 시 실제 시간으로 보정합니다. 화면 밖 시안에는 반복 효과를 실행하지 않습니다.

OS의 `prefers-reduced-motion` 또는 페이지의 ‘움직임 줄이기’를 켜면 효과를 생략하고 숫자·상호작용 결과만 표시합니다. 페이지의 선택으로 OS 설정을 무시하지 않습니다. 다크/라이트와 모바일 한 열·데스크톱 세 열을 제공합니다.

추천: 1번은 기본 카운트다운에 가장 작은 변경으로 적용하기 좋습니다. 2번은 숫자의 가독성을 유지하면서 상시 표시 면에 적합한 후보입니다. 3번은 앱에서 잠깐 의식적으로 바라보는 상호작용으로 검토할 수 있습니다. 전부 함께 적용하지 않고 하나를 선택하거나 상시 효과 하나와 선택적 상호작용을 분리합니다.

iPhone OS 위젯에서 앱과 동일한 매초 사용자 정의 애니메이션이나 길게 누르는 제스처를 제공한다고 약속하지 않습니다. 기존 시스템 숫자 갱신을 유지하고 플랫폼별 지원을 검증한 뒤 별도 결정합니다.
